## 维护约定

- 项目首页维护项目介绍与快速启动；专题细节放在对应文档中。
- 更新配置、评分口径或数据结构时，同步对应专题文档和相关链接。
- 文档以文字、表格和代码示例为主，不保留临时界面验收截图。
- `examples/` 保存有说明和来源的示例报告；原始评分快照由 `server/internal/store/fixtures/` 维护，课程、选课和补充账号由 `server/internal/store/course_seed.go` 维护。
